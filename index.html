관심 분야

수업을 설계하고 학생들과 함께 탐구할 때 중심에 두는 세 가지 영역입니다.

01

교육공학

02

AI 융합교육

복잡한 코딩 없이도 실제 데이터를 살펴보고 예측 모델을 만들어 보는 교과 융합 수업을 기획합니다.

03

청소년지도

학생들이 스스로 질문을 세우고 또래와 협력하며 성장할 수 있는 안전한 배움의 경험을 함께 만듭니다.

데이터 기반 AI 융합 수업 프로젝트

오렌지3로 전복 무게 예측하기

전복의 길이, 지름, 높이 같은 측정 데이터를 노코드 데이터 분석 도구인 오렌지3(Orange3)로 불러와, 어떤 특징이 전복 무게를 예측하는 데 중요한지 학생들과 직접 실험하며 비교합니다.

  1. 1단계 전복 데이터 표 살펴보고 이상치·특징 고르기
  2. 2단계 오렌지3 위젯 연결로 회귀 예측 모델 학습시키기
  3. 3단계 예측값과 실제 무게 오차 비교하며 결과 해석하기

데이터의 상관관계를 시각화하고 예측 모델의 정확도를 눈으로 확인하는 수업 흐름
